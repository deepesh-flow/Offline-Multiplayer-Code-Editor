Our Solution

An editor that never loses your work

🧮
CRDT — Conflict-Free by Math
We use Yjs (CRDT) — every character has a unique ID. Even if 4 users type the same word offline for 3 hours, all copies mathematically converge to identical text with zero conflicts when they reconnect.
💾
IndexedDB — Works in Airplane Mode
Every keystroke is instantly saved to IndexedDB (browser hard drive). Close the laptop, lose power, lose internet — when you open the browser again, every character is exactly where you left it.
📶
Auto-Merge on Reconnect
The moment internet returns, clients exchange State Vectors — a compact summary of what each peer has. Only the missing diffs are synced. Zero data duplication, zero conflicts.
👁️
Live Cursors + Per-User Undo
See every teammate's cursor in real-time with colored name tags. Ctrl+Z undoes only YOUR edits — never accidentally deletes a teammate's work.
Technical Deep Dive

Why CRDT beats OT for offline

Capability OT (Google Docs) CRDT — Yjs (Ours)
Works without internet ✗ Needs central server ✓ Fully local
Merge concurrent edits ✗ Server must arbitrate ✓ Math guarantees merge
Zero data loss on reconnect ✗ Conflicts possible ✓ Mathematically proven
No central coordinator needed ✗ Required ✓ Peer-to-peer
Merge speed O(n²) complexity ✓ < 2ms (Yjs YATA algorithm)
💡 Analogy: OT is like needing a referee for every move in chess. CRDT is like addition — 2+3 = 3+2 regardless of arrival order.

📡 Online Mode
WebSocket relays binary CRDT diffs between all peers in real-time. Awareness protocol broadcasts live cursors, names, colors.

WebSocket is gone. Yjs writes every edit directly to IndexedDB. All changes are queued safely. App never shows an error.
